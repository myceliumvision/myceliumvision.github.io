Mycelium

Mold monitor · camera, thermal and machine data, for learning

Watches the injection molding machine with a photo camera and a thermal camera, labels each part, and keeps the data - ready for the models.

Download the newest version

Windows 10 and 11 · installs for your Windows user, no administrator rights · about 290 MB

Only for the people given access. Sign in to GitHub with the account that was invited - then the button downloads the newest version.

Install in three steps

1

Download

The button downloads Mycelium-Setup.exe, the newest version. If GitHub asks, sign in first - then click the button again.

2

Install

Double-click it and click Install. If Windows says Windows protected your PC, click More info, then Run anyway - the installer isn't code-signed.

3

Sign in once

Start Mycelium and click Sign in with GitHub at the top. From then on it shows your version at every start and offers each new one.

The cameras

  • XIMEA photo camera: also install the XIMEA Software Package (its driver).
  • Optris thermal camera: nothing to install - it comes with the program.

Good to know

  • Your data stays. Batches, photos, tables and settings are kept apart, in Documents, and are never touched by installing.
  • Every version is kept. A new one is added next to the ones before - you can start any of them. All versions

The button shows "Page not found"?
